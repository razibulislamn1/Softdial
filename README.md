## 🌟 Soft Dial কী?

**Soft Dial** একটি হালকা, সুন্দর ও ব্যবহারবান্ধব Android কলিং অ্যাপ। শুধু আপনার SIP তথ্য দিন, নাম্বার লিখুন, আর এক ট্যাপেই কল করুন — কোনো ঝামেলা নেই, কোনো জটিলতা নেই।

> **Soft Dial is a light, elegant Android calling app.** Enter your SIP details, type a number, tap once — and you are talking.
